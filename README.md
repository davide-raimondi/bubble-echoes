# 🫧 Bubble Echoes

> Puzzle arcade bubble shooter con mira laser predittiva, sfere speciali e controlli touch nativi, sviluppato in architettura single-file.

[![Gioca Ora](https://img.shields.io/badge/GIOCA%20ORA-Live%20su%20GitHub%20Pages-success?style=for-the-badge&logo=github)](https://davide-raimondi.github.io/bubble-echoes/)

**Bubble Echoes** porta l'esperienza classica del bubble shooter su web mobile con una fisica di rimbalzo precisa, effetti visivi moderni e un controllo touch calibrato per tiri rapidi e strategici.

## ✨ Funzionalità Principali

- 🎯 **Mira Laser Predittiva**: Sistema di puntamento fluido che mostra la traiettoria di rimbalzo per colpi di precisione.
- 💥 **Sfere Speciali & Combo**: Attiva reazioni a catena ed effetti esplosivi per liberare il tabellone e massimizzare il punteggio.
- 📱 **Controlli Touch Nativi**: Interfaccia verticale progettata per giocare comodamente con una sola mano su smartphone.
- 🚀 **Single-File Architecture**: Tutto il gioco è contenuto in un singolo file HTML, CSS e JavaScript.

## 🛠 Tecnologie Utilizzate

- **HTML5 Canvas** per il calcolo geometrico delle traiettorie e il rendering delle sfere.
- **CSS3** per il layout responsive e le animazioni dell'interfaccia.
- **Vanilla JavaScript (ES6+)** per gli algoritmi di matching sulla griglia, la fisica dei rimbalzi e la **Web Audio API**.
